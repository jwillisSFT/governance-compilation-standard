# Normative Specification Modules

v0.1.0 is split into focused modules so that semantic changes can be reviewed independently.

| Module | Purpose |
|---|---|
| `GC-Terminology.md` | normative vocabulary and requirements language |
| `GC-Core.md` | lifecycle, authority boundary, transformation, activation, runtime, claim limits |
| `GC-GIR.md` | canonical Governance Intermediate Representation |
| `GC-Transition-Governance.md` | Permitted Action Set, regions, CTCs, typed composition, target state, closure |
| `GC-Package-and-Lifecycle.md` | immutable package, issuance, activation, runtime consumer, change |
| `GC-Compiler-Qualification.md` | intended-use qualification of human/software/AI-assisted compilation capabilities |
| `GC-Evidence-and-Assurance.md` | evidence roles, assurance claim boundaries, continuing assurance |
| `GC-Operating-Protocol.md` | package exchange and lifecycle interoperability semantics |
| `GC-Profile-Model.md` | specialization and extension rules |
| `GC-Security.md` | trust, evidence source, package protection, deployment non-bypassability |
| `GC-Conformance.md` | bounded conformance claims and assessment objects |

The individually identified normative statements are indexed under `../requirements/`.
