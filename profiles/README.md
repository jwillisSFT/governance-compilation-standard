# Profiles

Profiles specialize the Governance Compilation Core without redefining core semantics.

| Profile | v0.1 status | Purpose |
|---|---|---|
| `core` | normative | minimum shared lifecycle/semantic requirements |
| `rights-affecting` | draft | contestability/redress representation where required |
| `security-high-assurance` | draft | cryptographic trust and stronger deployment evidence |
| `distributed-transition-experimental` | experimental | multi-step, partial-commit, compensation, and composite closure research |

Only the Core profile is considered normative/stable enough for v0.1 conformance claims. Draft/experimental profiles are published to accelerate implementation and research review.
