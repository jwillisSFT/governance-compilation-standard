# Requirements

`GC-Normative-Requirements.csv` is the machine-readable v0.1.0 requirement index. `GC-Normative-Statements.md` is the human-readable rendering.

Requirement identifiers are stable release identifiers. They are not line numbers. If a future release withdraws or supersedes a requirement, its identifier remains reserved.

The detailed specification module remains authoritative when the short catalog statement requires context. Any inconsistency between a catalog statement and its detailed normative source is a specification defect and should be reported.
