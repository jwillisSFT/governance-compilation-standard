# Thesis, Dissertation, and Capstone Topics

These are research prompts, not endorsements of the specification's correctness.

## Master's-scale

- Implement a GIR-to-Cedar or GIR-to-Rego projection and measure semantic loss.
- Build a CTC validator with satisfiability diagnostics for a bounded domain.
- Compare independent modeler agreement on action-region classification.
- Implement package lifecycle/activation records and test stale-package refusal.
- Develop a deployment non-bypassability assessment method for one cloud operation.
- Model contestability propagation for one rights-affecting workflow.

## Ph.D.-scale

- Formal semantics and compositional proof theory for typed CTC composition.
- Automated region-completeness analysis under bounded/open-world assumptions.
- Verified/refinement-preserving Governance Compilation projection.
- Cross-domain empirical evaluation of governance-error reduction and institutional cost.
- Formal distributed-transition governance with partial commitment and composite closure.
- Authority-provenance logic spanning institutional instruments, delegation, revocation, and runtime commitment.
- Probabilistic evidence with deterministic authority/closure semantics.
