# Release Notes — v0.1.0

**Release class:** Draft Public Review  
**Date:** 2026-11-07

v0.1.0 converts the Governance Compilation research model into a substantial, implementation-neutral open-specification baseline.

## Highlights

- normative Core, GIR, transition-governance, package/lifecycle, profile, security, and conformance modules;
- machine-readable normative requirement catalog;
- JSON Schema 2020-12 interchange profile;
- four worked examples: minimal, financial transaction, identity provisioning, software deployment;
- formal property catalog and proof obligations;
- conformance-claim structure and test assertions;
- negative fixtures for authority expansion, missing region coverage, silent weakening, stale authorization, and false closure;
- bounded analytical suite retained with explicit evidence limits;
- repository integrity/validation tooling;
- research and replication guidance.

## Compatibility

There is no earlier stable open-specification release. Breaking changes are expected before v1.0.0 and will be recorded in `CHANGELOG.md`.

## Known limitations

See `STATUS.md`, `formal/GC-Assumptions-and-Bounds.md`, and `research/open-problems.md`.
