# Specification Status

## v0.1.0 — Draft Public Review

This release is the first substantial public specification baseline derived from the Governance Compilation research model.

### Established in this repository

- stable terminology for the v0.1 core;
- a technology-neutral lifecycle and conformance boundary;
- a JSON interchange representation for core GIR objects;
- authority-bounded action, region, CTC, evidence, target-state, and closure structures;
- an identified normative-requirement set;
- a formal-property and proof-obligation catalog;
- machine-readable examples and negative fixtures;
- finite semantic checks and the bounded analytical suite;
- profile and conformance-claim structures.

### Not established by v0.1.0

- consensus adoption by an SDO or standards community;
- complete machine-checked proof of the reference model;
- a formally verified compiler or projection toolchain;
- production scalability or operational effectiveness;
- legal compliance in any jurisdiction;
- cross-vendor interoperability established by independent implementations;
- certification or accreditation of any product or organization;
- deployment non-bypassability merely from package conformance.

### Public-review priorities

1. identify semantic gaps in the GIR Core;
2. test CTC completeness across additional domains;
3. challenge the typed-composition model;
4. formalize proof obligations in independent tools;
5. implement at least two independent projections;
6. test package and lifecycle interoperability;
7. develop deployment evidence for non-bypassability;
8. evaluate contestability/redress and distributed-transition profiles.
