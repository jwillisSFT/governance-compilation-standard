# Machine-Readable Examples

All examples are synthetic and informative. They demonstrate the same core semantics in different domains:

- `minimal/` — smallest end-to-end configuration transition;
- `financial-transaction/` — overlapping base/high-value transfer regions and additive controls;
- `identity-provisioning/` — privileged entitlement with separation-of-duty and target-state readback;
- `software-deployment/` — digest-bound production promotion with SBOM/approval and post-deployment verification.

The examples intentionally avoid implementation-specific runtime artifacts. Any independent runtime or policy engine may be used to implement projections.

Placeholder digests are labeled as example values and provide no cryptographic assurance.
