# Validation Materials

## Bounded analytical suite

`bounded-analytical-suite/` is the finite executable validation suite associated with the Governance Compilation research monograph.

It is intentionally labeled **bounded analytical validation**. It is not Alloy/SMT/TLA+/theorem-prover verification and does not establish universal correctness.

Release-level schema, reference, conformance-fixture, and repository-hygiene checks are run by `tools/validate_repo.py`.
