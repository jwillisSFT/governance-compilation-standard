# Implementation Independence

Governance Compilation is intentionally independent of any one runtime control plane or product.

A conforming implementation may be:

- a standalone compiler/toolchain;
- a manual or tool-assisted governance engineering process;
- a policy-as-code pipeline with an adequate canonical model and evidence layer;
- a formal-model-driven compiler;
- a service producing/validating governance packages;
- an enterprise platform with embedded compilation functions;
- another architecture that preserves the normative responsibilities.

The core specification does not require AGCP. AGCP is a separate runtime-governance reference realization in the broader RGE work and is not a dependency of the Governance Compilation specification.

The repository must not absorb proprietary AGCP code, keys, configurations, assessment methods, training environments, or customer deployment material.
