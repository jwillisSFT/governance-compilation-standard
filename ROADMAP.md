# Roadmap

## v0.1 — Public baseline

- normative core and schemas;
- formal property registry;
- examples and bounded validation;
- conformance model.

## v0.2 — Independent implementation feedback

Target evidence:

- at least one independent GIR producer or parser;
- at least one independent target projection;
- schema and semantic defects reported through public review;
- expanded negative test vectors;
- initial interoperability transcript format.

## v0.3 — Formalization profile

Target evidence:

- executable formal models for selected properties;
- explicit proof-profile examples;
- machine-readable property-result records;
- clearer refinement/projection semantics.

## v0.4 — Deployment and operating-protocol profile

Target evidence:

- package exchange/verification tests;
- activation/revocation/supersession interoperability;
- deployment non-bypassability evidence pattern;
- runtime-consumer test harness.

## v0.5 — Multi-domain evaluation

Target evidence:

- independent examples in multiple legal/operational domains;
- cross-domain CTC evaluation;
- usability and defect-detection evidence;
- profile refinement.

## v0.9 — Candidate standard

Entry criteria should include multiple independent implementations, resolved core semantic issues, repeatable conformance tests, documented formal-analysis results, and a public disposition record for major review comments.

## v1.0 — Stable open specification

v1.0 should not be declared solely on editorial completeness. It should require implementation and interoperability evidence sufficient to justify a stable normative baseline.
