# Code of Conduct

This project is a technical and research forum. Participants are expected to:

- critique arguments and artifacts rather than people;
- identify evidence and assumptions;
- distinguish normative disagreement from implementation preference;
- preserve dissent when consensus is not reached;
- avoid harassment, discrimination, and personal attacks; and
- disclose material conflicts of interest when making assessment or conformance claims.

The Specification Editor may moderate contributions that materially violate these expectations.
