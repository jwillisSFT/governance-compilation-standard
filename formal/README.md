# Formal Model and Assurance Properties

This directory separates **properties to be established** from **evidence actually obtained**.

- `GC-Reference-Model.md` — canonical mathematical/relational abstraction.
- `GC-Property-Catalog.md` / `property-catalog.json` — stable property identifiers and current status.
- `GC-Proof-Obligations.md` — claim vocabulary and proof/analysis discipline.
- `GC-Assumptions-and-Bounds.md` — minimum scope information for meaningful formal claims.

The v0.1.0 repository does not claim complete machine-checked verification. See `../validation/` and `../docs/research-status.md`.
